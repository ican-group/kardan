# ghcup channel for plinthc

This branch only carries the ghcup metadata for plinthc; it is not
part of the source tree. Both files are generated by CI on a `v*` tag
(see the `release` job in `.github/workflows/ci.yml`) -- do not edit
them by hand.

    ghcup config add-release-channel https://raw.githubusercontent.com/ican-group/plinthc/ghcup-channel/ghcup-plinthc.yaml
    ghcup install plinthc latest
